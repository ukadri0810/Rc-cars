# KAS RC Arena v3.16 QA

## Added
- EOD Single Day / Custom Range mode switch.
- Inclusive From/To date filters.
- This Month and Last 7 Days shortcuts.
- Range totals for sales, expenses, net, payment mix, activity mix, and cash balance.
- Expense category totals.
- Per-day summary with closing status and direct open-day navigation.

## Safety / UX decisions
- Custom Range is view-only. Expense entry and day closing stay in Single Day mode so a range report cannot accidentally assign an expense or closing to the wrong date.
- Future dates are clamped to today. If From is after To, the range is normalized automatically.
- Existing local IndexedDB data requires no migration.
