# KAS RC Arena v3.17 QA

## Battery charge performance
- Added per-charge Used (minutes) and Earned (revenue) counters.
- Main Equipment/Battery screens show only the two simple values to avoid clutter.
- Mark Ready after Charging archives the prior charge and resets both counters to zero.
- Added Owner-only Battery History modal for previous charges and lifetime totals.
- Timed ride battery swaps retain the battery charge-session ID, so delayed ride revenue is credited to the correct previous charge even if that battery was recharged before the ride finished.
- Ride pause/resume now records active battery time rather than counting paused time.
- Timed ride revenue is split by battery powered time if more than one battery was used.
- Sumo match revenue is split equally across participating batteries; runtime stops at elimination/completion.

- app.js syntax checked with Node.
- sw.js syntax checked with Node.
- HTML duplicate IDs checked.
