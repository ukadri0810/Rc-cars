# KAS RC Arena v3.11 QA

## Scope
Timer-only stabilization and battery inventory visibility. No lap mode was added.

## Battery fixes
- Added normalization for battery status, type, assignment, cycles and runtime.
- Reconciles vehicle.currentBatteryId with battery.assignedVehicleId.
- Orphaned installed/in-use batteries are returned to Ready instead of disappearing from normal operations.
- Added Total/Ready/In Use/Charging/Needs Charge/Issue filters in Battery Station.
- New batteries default to Ready, are saved immediately, and are highlighted in Battery Station.
- Owner Battery Management displays inventory count, status labels and a direct link to Battery Station.

## Timer-only safeguards
- Package minutes are clamped to at least 1 minute.
- Package and extension prices are clamped to zero or higher.
- Timer remains timestamp based (`endsAt - current time`) so refresh/offline operation does not alter elapsed time.
- No lap fields, lap counters, lap package modes or sensor hooks were introduced.

## Static QA performed
- `node --check app.js`: passed.
- `node --check sw.js`: passed.
- `manifest.json`: valid JSON.
- Duplicate HTML IDs: none.
- SVG references: all referenced symbols exist.
- Service worker cache bumped to v3.11.

## Note
Some Owner Console inputs are rendered dynamically, so static HTML ID scans will not find settings fields such as `settingBusiness`; those IDs are created by `ownerSettings()` at runtime by design.
