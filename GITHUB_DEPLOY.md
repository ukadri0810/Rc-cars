# GitHub Pages deployment

1. Create a GitHub repository, for example `kas-rc-arena`.
2. Upload the **contents** of this folder to the repository root. `index.html` must be at the repository root.
3. In GitHub open **Settings -> Pages**.
4. Under **Build and deployment**, choose **GitHub Actions**.
5. Push to the `main` branch.
6. Open the repository **Actions** tab and wait for `Deploy KAS RC Arena to GitHub Pages` to finish.

The app uses relative paths and is suitable for a GitHub project Pages URL.
