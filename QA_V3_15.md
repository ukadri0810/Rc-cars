# KAS RC Arena v3.15 — EOD & Friction QA

## Added
- Owner Console **EOD** tab with date navigation.
- Daily Sales, Expenses, Net after expenses and Expected Cash.
- Timed Ride and Sumo sales breakdown.
- Cash / UPI / Other sales breakdown.
- Owner-only quick expense entry with category, payment method and note.
- Expense delete/correction workflow.
- Close Day / Update Closing with optional actual cash count and closing note.
- Closing is blocked while that day's ride or Sumo session is still active.
- Closed-day records warn if sales or expenses are changed after closing.

## Friction reductions
- New Ride remembers the last-used payment method.
- Sumo, ride extensions and expenses also reuse the last-used payment method where appropriate.
- First valid ride package remains preselected, so a standard walk-in can be started with very few taps.
- New Ride primary action is sticky on mobile so the operator does not need to scroll back to the bottom.
- A queued timed-ride customer skips vehicle selection when exactly one eligible vehicle is free.
- A ride already at 00:00 completes in one tap; the reason dialog remains only for early completion.
- Transaction buttons are guarded against accidental double taps.
- Mobile bottom navigation is correctly sized for all five operational destinations.
- Expense modal stacks above Owner Console correctly on mobile.

## Operational principle
The counter workflow stays local-first. Fast operator actions change local state immediately and are not blocked by future Firebase connectivity. Cloud sync should remain background-only and non-intrusive.
