# KAS RC Arena v3.14 QA

## Sumo setup changes
- Ready Sumo vehicles auto-assign on new match.
- Assignment ranking rotates least-used vehicles first.
- 4/5 player changes preserve names and reassign vehicles automatically.
- Manual override is one tap on the assigned vehicle chip; it cycles only through unused ready Sumo vehicles.
- Reassign All is available as a single action.
- Removed the repeated vehicle grid under every participant.
- Mobile participant setup uses a compact two-column layout and falls back to one column at very narrow widths.
- Match total and Start Match stay sticky at the bottom of the setup modal.

## Compatibility
- Existing Sumo match records are unchanged.
- Existing pricing, queue and battery rules are unchanged.
- No lap mode was added.
