# KAS RC Arena v3.10 – Owner Settings & Persistence QA

## Fixed
- Add Battery now creates a unique ready battery, immediately re-renders, scrolls to the new row, focuses the code field, and confirms with a toast.
- Add Package now creates a package in the active/default pricing profile, immediately re-renders, scrolls to the new row, focuses the name field, and confirms with a toast.
- Add Vehicle, Vehicle Type, Battery Type, Extension, Pricing Profile and Extension Profile now give visible confirmation and focus the new record.
- Owner fields now auto-save locally on blur/change. Explicit Save buttons remain for confirmation.
- Ride Timer settings now have their own Save Timer Settings button; previously the timer values were only committed by the Business Settings save button.
- IndexedDB writes are serialized using immutable snapshots so rapid edits cannot persist out of order.
- Battery and vehicle codes are checked for duplicates on explicit save.
- Auto-saving a vehicle battery-type change now safely releases an incompatible assigned battery.
- Added visual "Changes are saved locally" notice in editable Owner Console modules.
- Added highlight/focus feedback for newly created rows.
- Service worker cache version bumped to v3.10 so GitHub Pages/PWA clients receive the corrected JavaScript.

## Static QA performed
- JavaScript syntax validated with Node for app.js and sw.js.
- manifest.json validated as JSON.
- Checked index.html for duplicate IDs: none found.
- Checked action-style data attributes against code references: no orphan action attributes found in the source scan.

## Persistence behavior
Owner Console edits are local-first. Changes are stored in IndexedDB and also marked for future cloud synchronization. Firebase is not required for these settings to work.
