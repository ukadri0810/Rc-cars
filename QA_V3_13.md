# KAS RC Arena v3.13 QA

## Scope
Simplified day-to-day equipment operations for both Owner and Operator without changing the timer-based rental model or RC Sumo workflow.

## Changes reviewed
- Replaced operator Batteries navigation label with Equipment.
- Combined vehicle status, battery rack, charging and maintenance actions on the Equipment screen.
- Added Attention panel for missing batteries, batteries needing charge and vehicles in maintenance.
- Added compatible least-used battery recommendation.
- Added one-tap recommended battery assignment.
- Battery swap automatically moves the old battery to Needs Charge.
- Charging remains physically confirmed by the user: Start Charging then Mark Ready.
- Owner Console Fleet, Batteries and Maintenance were consolidated into Equipment.
- Advanced inventory/settings remain available in collapsed sections.
- Fixed battery issue/ready actions so vehicle assignment references are cleared consistently.
- Improved swap instructions and active-session battery state handling.

## Operational rule
Software can automate bookkeeping/state transitions, but it cannot know that a physical battery was connected, installed or repaired without hardware telemetry. The user gives that physical command with one tap; the system handles the dependent software work automatically.
